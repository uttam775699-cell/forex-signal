# Money Crash Files: channel setup (copy-paste)

Everything below is for YouTube Studio → **Customization** and **Settings**. Nothing here changes the channel's
country or residence (leave that as it is).

## 1. Customization → Profile
- **Name:** Money Crash Files
- **Handle:** @MoneyCrashFiles (keep)
- **Picture:** `channel/avatar.png` (800×800)
- **Banner:** `channel/banner.png` (2560×1440; all text sits inside the 1546×423 safe area, so it shows on phone, TV and desktop)
- **Description:**

```
The wildest true stories of money gone wrong in America — frauds, heists, scams and crashes — told in 60 seconds as a cartoon.

How did one ex-cop steal every big McDonald's Monopoly prize? How did a bank vanish in a weekend? Every story is real, and every number is checked against at least two reliable sources (links in each video's description).

New Short every day. Subscribe if you like your history with a plot twist.
```

- **Links:** none for now (add a website or X/Instagram later if you create one).
- **Contact email:** optional (a business email helps sponsors find you later).

- **For returning subscribers / new visitors:** leave empty until there is a long-form video; Shorts shelf shows automatically.

## 5. Settings → Upload defaults (saves time every day)
- **Title:** leave empty
- **Description:** 
```
Every story is real. Sources are listed below.

New 60-second money disaster every day → @MoneyCrashFiles
#shorts #moneyhistory #truestory
```
- **Visibility:** Private (you publish after review)
- **Category:** Education
- **Language:** English · **Caption certification:** none · **Comments:** allow all, hold potentially inappropriate
- **Altered or synthetic content:** "Yes" only if a video shows realistic-looking AI people or events; our cartoons are clearly
  animated, so normally **No** (YouTube does not require disclosure for clearly unrealistic animation). The voice is AI
  (ElevenLabs) but not imitating a real person, which also does not require disclosure.

## 6. Clean-up (recommended)
The 5 quiz / riddle / flag Shorts are off-niche and tell YouTube the wrong audience. Set them to **Private**
(Content → select → Visibility → Private). The Lehman, Enron, paycheck and credit-score Shorts can stay.

## 7. Every upload
Use the `upload.md` that comes with each video: title, description (with sources), tags, pinned comment.
Publish at **10:30 PM IST** (12:00 PM ET). Pin the comment right after publishing. Add the Short to its playlist.
